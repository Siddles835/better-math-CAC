# MathLift purpose

MathLift is a K–2 classroom app. Students travel a solar system while practicing counting, addition, and subtraction. Teachers create a class code, unlock planets, and see live progress.

The product is built for the moment after a child answers — not the score, the strategy. On-device models turn taps, retries, and written digits into a named misconception and a next planet. Drawings stay on the device. Teachers get a short class briefing they can use tomorrow.

A sample classroom and a methods page are in the app so a reviewer can read the teacher view and the model card without creating an account.
